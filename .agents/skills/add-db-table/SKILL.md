# Add a database table

Types are derived, never written by hand: Drizzle table → `models.*` (generated by `drizzle-orm/zod`) → refined in `@orkide/validators` → `z.infer`.

## 1. Schema

`packages/db/src/schema/<area>.ts` (pick the closest of `content`, `taxonomy`, `media`, `engagement`; export new files from `schema/index.ts`). Use the shared helpers from `../columns.ts`:

```ts
export const note = defineTable("note", {
  id: id(),                              // UUIDv7 text primary key
  postId: ref().references(() => post.id, { onDelete: "cascade" }),
  title: text().notNull(),
  ...timestamps(),                       // createdAt / updatedAt (ms)
}, (t) => [index("note_post_idx").on(t.postId)]);
```

- IDs are UUIDv7 strings via `id()`; public URLs use slugs. Translated content follows the `*_translation` pattern (`locale()` + `slug()` with a unique `(locale, slug)` index).
- Never edit `schema/auth.ts` (generated by `pnpm --filter @orkide/auth auth:generate`).

## 2. Relations

Add the table to `packages/db/src/relations.ts` (`defineRelations`, RQB v2) in both directions so `db.query.<table>.findMany({ with })` works.

## 3. Migration (generated, never hand-edited)

```bash
pnpm --filter @orkide/db db:generate     # writes packages/db/migrations/<timestamp>_<name>/
pnpm --filter @orkide/db db:check
pnpm --filter @orkide/api db:migrate:local
```

Review the SQL, commit the whole folder. Tests apply all migrations automatically. Production: the API Workers Build runs `db:migrate:remote` before every deploy (`docs/operations.md`), so migrations must stay backwards compatible with the previous code (add columns/tables first, drop later).

## 4. Derived models and validators

`models.insert.note` / `models.select.note` / `models.update.note` exist automatically (see `packages/db/src/models.ts`). In `packages/validators/src/<area>.ts` refine at the edge: `models.insert.note.pick({ title: true }).extend({ title: z.string().trim().min(1).max(120) })`. Add a case to `validators.test.ts`.

## 5. Verify

`pnpm --filter @orkide/db test && pnpm typecheck && pnpm test`. For queries, write the repository in an API module (`add-api-module` skill). Seed data for the local e2e/Lighthouse runs lives in `apps/api/seed/e2e.sql`; extend it if pages need rows of the new table.
